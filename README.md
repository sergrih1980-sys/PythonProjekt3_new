# Skypro Widget for Client Banking Operations


Виджет для обработки клиентских банковских операций: маскировка конфиденциальных данных, фильтрация и сортировка операций.

## Описание функционала

Проект включает три основных модуля для работы с банковскими данными.

## Модули

### 1. `masks`

Функции для маскировки конфиденциальных данных.

- **`get_mask_card_number(card_number: str) -> str`**  
  Маскирует номер карты в формате: `XXXX XX** **** XXXX`.  
  **Пример:**  
  `7000792289606361` → `7000 79** **** 6361`

- **`get_mask_account(account_number: str) -> str`**  
  Маскирует номер счёта в формате: **`XXXX`.  
  **Пример:**  
  `73654108430135874305` → **`4305`

### 2. `widget`

Работа с банковскими данными: автоматическое определение типа данных, преобразование даты.

- **`mask_account_card(card_or_account_data: str) -> str`**  
  Автоматически определяет тип (карта/счёт) и применяет маску.  
  **Примеры:**  
  - `Visa Platinum 7000792289606361` → `Visa Platinum 7000 79** **** 6361`  
  - `Счёт 73654108430135874305` → `Счёт **4305`

- **`get_date(data_info: str) -> str`**  
  Преобразует дату из формата `YYYY-MM-DDTHH:MM:SS.ffffff` в `ДД.ММ.ГГГГ`.  
  **Пример:**  
  `2024-03-11T02:26:18.671407` → `11.03.2024`

### 3. `processing`

Фильтрация и сортировка банковских операций.

- **`filter_by_state(operations: list, state: str = 'EXECUTED') -> list`**  
  Фильтрует операции по статусу.  
  **Параметры:**  
  - `operations` — список операций (словари);  
  - `state` — статус (по умолчанию `'EXECUTED'`).

  **Пример:**
  ```python
  from processing import filter_by_state

  operations = [
      {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
      {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
  ]

  executed_operations = filter_by_state(operations)
  # [{'id': 41428829, ...}]

## `filter_by_currency(spisok, valuta)`


**Назначение**  
Фильтрует список транзакций, оставляя только те, где код валюты совпадает с заданным.

**Синтаксис**
```python ```
def filter_by_currency(spisok, valuta):
    """
    Функция принимает список транзакций (словари) и код валюты,
    возвращает объект filter, содержащий только транзакции, где код валюты
    совпадает с заданным.
    """
    return filter(
        lambda x: x["operationAmount"]["currency"]["code"] == valuta,
        spisok
    )

## `transaction_descriptions(transactions)`

**Назначение**  
Генератор, последовательно возвращающий описания транзакций из переданного набора данных. При отсутствии описания возвращает пустую строку.

**Синтаксис**
```python```
`def transaction_descriptions(transactions):`
    """
    Генератор, возвращающий описания транзакций по очереди.
    """
    `for transaction in transactions:`
        # Безопасное получение описания: если ключа нет — возвращаем пустую строку
        `description = transaction.get('description', '')
        yield description`

# Пример списка транзакций
`transactions` = [
    {'description': 'Покупка продуктов'},
    {'amount': 1000},  # Нет поля 'description'
    {'description': 'Оплата интернета'},
    {}  # Пустой словарь
]

# Итерация по генератору
for desc in transaction_descriptions(transactions):
    print(desc)

## `card_number_generator(start, end)`


**Назначение**  
Генератор, создающий номера банковских карт в стандартном формате: `XXXX XXXX XXXX XXXX` (четыре группы по 4 цифры, разделённые пробелами).

**Синтаксис**
```python```
`def card_number_generator(start, end):
    """
    Генератор номеров банковских карт в формате XXXX XXXX XXXX XXXX.
    """
    for num in range(start, end + 1):`
        # Формируем 16‑значный номер с нулями слева
        `padded = str(num).zfill(16)`
        # Разбиваем на группы по 4 цифры
        `yield f"{padded[:4]} {padded[4:8]} {padded[8:12]} {padded[12:16]}"`

**Код примера**
```python```

    print(card_number)`

# Декоратор `log` для логирования вызовов функций


Декоратор `log` позволяет автоматически записывать в лог информацию о вызовах функций: аргументы, результат выполнения или ошибку. Поддерживает запись в файл или вывод в консоль.

## Основные возможности
- Логирование **успешных вызовов**: имя функции, результат, аргументы (`*args`, `**kwargs`).
- Логирование **ошибок**: тип исключения, сообщение, переданные аргументы.
- Гибкий выбор места вывода:
  - В файл (если указан `filename`).
  - В консоль (если `filename=None`).
- Сохранение сигнатуры и документации исходной функции (`functools.wraps`).

## Установка и использование
Декоратор не требует установки — достаточно скопировать код в модуль.

# Модуль конвертации валют

## Описание


Модуль `currency_conversion` предназначен для конвертации валютных сумм из указанных валют (`USD`, `EUR`) в рубли (`RUB`) с использованием внешнего API.

**Основные правила:**
- Если валюта — `RUB`, возвращается исходная сумма.
- Для других валют или отсутствующих данных возвращается `0.0`.

## Функция

### `currency_conversion(transaction: dict) -> float`


**Назначение**  
Конвертирует сумму из заданной валюты в рубли через внешний API.


**Параметры**  
`transaction` (`dict`) — словарь с данными о транзакции. Должен содержать:
- `operationAmount.amount` — сумма операции;
- `operationAmount.currency.code` — код валюты (`RUB`, `USD`, `EUR` и др.).

**Возвращаемое значение**  
- `float` — сумма в рублях (`RUB`);
- `0.0` в следующих случаях:
  - валюта не `RUB`, `USD` или `EUR`;
  - отсутствует `amount`;
  - ошибка при обращении к API;
  - сетевая ошибка.

## Логика работы

1. **Извлечение данных**  
   - Получает `amount` и `currency` из структуры `transaction`.


2. **Обработка RUB**  
   - Если валюта `RUB`, возвращает `amount` (или `0.0`, если `amount` равен `None`).


3. **Проверка для USD/EUR**  
   - Если `amount` отсутствует (`None`), возвращает `0.0`.

4. **Запрос к API**  
   - Формирует URL с параметрами:
     - `to=RUB` — целевая валюта;
     - `from_=<валюта>` — исходная валюта (`USD`/`EUR`);
     - `amount=<сумма>` — сумма для конвертации.
   - Отправляет GET‑запрос с заголовком `apikey`.


5. **Обработка ответа**  
   - При `status_code == 200`: возвращает `data["result"]` (сумма в рублях).
   - Иначе: выводит ошибку и возвращает `0.0`.


6. **Обработка исключений**  
   - Перехватывает сетевые ошибки (`requests.exceptions.RequestException`).
   - Возвращает `0.0` при любых исключениях.


## Пример использования

```python```
transaction = {
    "operationAmount": {
        "amount": 100.0,
        "currency": {
            "code": "USD"
        }
    }
}

result = currency_conversion(transaction)
print(result)  # Например: 9500.0 (если курс USD→RUB = 95)

## Функция `load_financial_operations`


**Назначение**  
Загружает финансовые операции из JSON‑файла в виде списка словарей. При любых ошибках возвращает пустой список.


## Синтаксис

```python```
`def load_financial_operations(filepath: str) -> list:`

**Параметры**
`filepath (str)` — путь к JSON‑файлу с данными операций.

**Возвращаемое значение**
`list` — список словарей с операциями, если:

- файл существует;

- файл не пуст;

- содержимое — корректный JSON;

- данные представлены в виде списка.

- [] (пустой список) в случаях:

- файл не найден;

- файл пуст;

- содержимое не является списком;

- ошибка чтения или декодирования JSON (например, синтаксическая ошибка).

## Логика работы
**Проверка существования файла**

- Если файл не существует (os.path.isfile(filepath) == False) → возвращается [].

- Чтение и парсинг JSON

- Файл открывается с кодировкой utf-8.

- Данные загружаются через json.load().

- Проверка типа данных

- Если загруженные данные — список (isinstance(data, list)) → возвращается data.

- Иначе → возвращается [].

- Обработка исключений

- Перехватываются ошибки:

- OSError, IOError — проблемы с доступом к файлу;

- json.JSONDecodeError — некорректный JSON.

- В случае любой из этих ошибок → возвращается [].

## Пример использования
```python```
`operations = load_financial_operations("data/operations.json")`
`print(operations)`  # Например: `[{'id': 1, 'amount': 1000}, ...]` или []

# Программа анализа банковских транзакций
**Описание**
## Консольное приложение для работы с банковскими операциями: загрузка, фильтрация, сортировка и вывод данных из файлов разных форматов (JSON, CSV, XLSX).

**Функциональные возможности**
- Загрузка данных из:

- JSON‑файлов;

- CSV‑файлов;

- XLSX‑файлов.

**Фильтрация операций по статусу `(EXECUTED, CANCELED, PENDING)`.**

- Сортировка по дате (по возрастанию/убыванию).

- Фильтрация по валюте (только рублёвые операции).

- Поиск по ключевому слову в описании операции.

- Форматированный вывод результатов.
